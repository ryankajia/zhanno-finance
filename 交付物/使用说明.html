湛诺财务系统

使用说明书　·　V1.0　·　Mac / Windows 双平台

三句话看懂这个软件
1. 解压后双击一个文件就能用，不需要安装 Python 或任何环境。
2. 所有账目都存在你自己的电脑里，不上传云端，断网也能记账。 （仅 AI 功能需要联网，且只发送你所提问的那句话，账本本身始终不离开你的电脑。）
3. 软件本体买断终身使用；AI 记账/查账为可选订阅，不订阅不影响其他所有功能。

一、你会收到什么

解压后你会看到下面这些内容。只需要关心加粗的那一个，其余都是软件运行必需的组件，请不要删除、改名或单独移动。

Windows 版

湛诺财务系统_v1.0_Windows/
├── 湛诺财务系统.exe   ← 双击这个启动
├── _internal/              ← 运行组件，请勿删除
└── 使用说明.html           ← 本文档

Mac 版

湛诺财务系统_v1.0_Mac.dmg   ← 双击打开，把图标拖进「应用程序」
└── 湛诺财务系统.app    ← 之后从「启动台」双击启动
⚠ 请整个文件夹一起保存
Windows 版不要只把 湛诺财务系统.exe 单独拷出来，它需要同目录下的 _internal 文件夹才能运行。建议把整个文件夹放到 D:\湛诺财务系统\ 这样的固定位置，再右键发送快捷方式到桌面。

二、第一次启动

Windows

  1. 解压压缩包右键 湛诺财务系统_v1.0_Windows.zip → 全部解压缩。注意：必须先解压，直接在压缩包里双击是打不开的。
  2. 双击 湛诺财务系统.exe首次启动约需 5–15 秒，请耐心等待，不要重复双击。
  3. 浏览器会自动打开软件界面出现在浏览器里，地址是 http://localhost:8000。这是本机地址，数据并没有上传到互联网。
如果 Windows 弹出蓝色的「已保护你的电脑」提示
这是因为本软件是独立开发者发布、未购买微软代码签名证书，并非病毒。
点击提示中的 「更多信息」 → 再点 「仍要运行」 即可。只需操作这一次。
如果防火墙询问网络访问权限，选择「允许」——软件需要在本机开一个端口显示界面。

Mac

  1. 双击 .dmg 文件把「湛诺财务系统」图标拖到旁边的「应用程序」文件夹，然后推出这个磁盘映像。
  2. 解除系统拦截（只需做一次）macOS 会拦截所有未经苹果公证的软件。请按下方对应你系统版本的方法操作。
  3. 之后正常双击即可解除一次后，以后每次直接双击图标就能打开。
⚠ 首次打开会看到安全提示，这是正常的
你可能会看到：
·「Apple 无法验证"湛诺财务系统"是否包含可能危害 Mac 安全或泄露隐私的恶意软件」
·「湛诺财务系统已损坏，无法打开，您应该将它移到废纸篓」
·「无法打开，因为无法验证开发者」

软件本身没有问题，也没有损坏。这是 macOS 对所有未购买苹果开发者公证的软件的统一拦截， 与软件是否安全无关。按下面任一方法解除即可。

方法 A：终端命令（最快，所有 macOS 版本通用 ✅ 推荐）

在「启动台」搜索并打开「终端」（Terminal），把下面这行完整复制粘贴进去，按回车：

xattr -cr /Applications/湛诺财务系统.app

可能会要求输入开机密码（输入时屏幕上不显示任何字符，这是正常的，输完直接回车）。 完成后关闭终端，双击图标即可正常使用。

方法 B：系统设置里放行

macOS 15 (Sequoia) / macOS 14 (Sonoma) 及更新版本：

  1. 先双击一次「湛诺财务系统」，出现拦截提示后点「完成」或「好」。
  2. 打开「系统设置」→「隐私与安全性」，向下滚动到「安全性」区域。
  3. 你会看到一行「已阻止使用"湛诺财务系统"，因为它来自身份不明的开发者」， 点击右侧的「仍要打开」按钮。
  4. 输入开机密码确认，在最后的弹窗里再点一次「打开」。

macOS 13 (Ventura) 及更早版本：可以直接按住 Control 键点击图标 → 选「打开」→ 弹窗里再点「打开」。

注意：macOS 15 (Sequoia) 起，「右键 → 打开」已被苹果取消。
如果你的系统是 macOS 15 或更新版本，请使用上面的方法 A 或方法 B。 在「系统设置 →「隐私与安全性」中看不到「仍要打开」按钮时，说明还没有先双击触发过一次， 请先双击一次软件再回去查看。

三、登录

默认用户名admin
默认密码123456
🔐 登录后请立即修改密码
点击左下角「修改密码」，设置一个你自己的密码（至少 6 位）。 这是保护账目数据的第一道防线，请务必第一时间完成。

四、功能导览

1. 仪表板 —— 打开就知道这个月的情况

登录后的首页。本月收入、支出、净结余、最大单笔一目了然，下方是分类金额分布和最近 10 笔记录。顶部如有税务申报提醒，会以醒目横幅显示。

2. 快速记账 —— 一句话记一笔

下方「手动录入」任何时候都能用：填金额、选分类、写经手人和日期，点确认入账即可。

如果你订阅了 AI 功能，上方的输入框支持直接说人话，例如输入「今天张三请客户吃饭花了 1500 元」，点「AI 智能解析」，系统会自动识别金额、分类、经手人和日期并填好表单，你确认无误后入账即可。

开通 AI 只需一步：把卖家给你的授权码粘贴到「系统设置 → AI 功能授权」里，点激活。 无需注册 AI 账号，无需填写任何 API Key。

3. 账目明细 —— 查账与批量管理

可按经手人、分类、年份、月份组合筛选。勾选左侧复选框可一次选中多笔，点「批量删除」一次性删除；点表头的复选框可全选当前列表。

4. 税务提醒 —— 不再错过申报期

内置中国大陆纳税申报日历，自动列出增值税、企业所得税、个人所得税、印花税等税种的申报截止日，并显示剩余天数；逾期会标红。申报完成后点「✓ 标记已申报」即可消除提醒。

首次使用请点右上角「纳税人设置」，选择你的增值税申报周期（按月 / 按季）、是否有员工等，提醒会据此自动调整。

申报期限依据国家税务总局办公厅《关于明确2026年度申报纳税期限的通知》（税总办征科函〔2025〕64号）。 房产税、城镇土地使用税、残保金等税种各地征期存在差异，个别行业另有特殊规定。 本功能仅作日程提醒，不构成税务意见，请以主管税务机关通知为准。

5. 报表导出 —— 发给合伙人或会计

选择日期区间和导出内容（全部 / 仅收入 / 仅支出），点「生成并下载 PDF」。PDF 内含分类汇总、人员汇总和明细清单。

在「PDF 密码」栏填写密码后，导出的 PDF 会被加密，对方需要输入该密码才能打开，适合发给外部会计或合伙人。留空则不加密。

6. 分类管理与系统设置

「分类管理」里可以新增自定义收支分类；系统内置分类不可删除，以保证历史数据完整。

「系统设置」中可管理团队账号：管理员可记账和管理，只读账号只能查看和导出报表、不能增删账目，适合给会计或合伙人使用。AI 授权码也在这里激活。

五、我的数据存在哪里？

账目数据完全保存在你自己的电脑上，不会上传到任何服务器。具体位置：

WindowsC:\Users\你的用户名\AppData\Roaming\湛诺财务系统\
Mac~/资源库/Application Support/湛诺财务系统/

其中 zhanno_finance.db 就是你的全部账目数据。

💾 请定期备份这个文件
软件卸载、重装、换电脑都不影响它，但如果电脑硬盘损坏，数据将无法找回。
建议每月把 zhanno_finance.db 复制一份到移动硬盘或网盘。
换新电脑时，装好软件后把这个文件覆盖过去，所有账目原样恢复。

六、常见问题

关不掉 / 浏览器关了软件还在运行？

关闭浏览器窗口只是关掉了界面，程序仍在后台。要彻底退出：
Windows：任务管理器（Ctrl+Shift+Esc）→ 找到「湛诺财务系统」→ 结束任务。
Mac：在程序坞图标上右键 → 退出。

不小心关掉浏览器页面怎么办？

只要程序还在运行，重新打开浏览器访问 http://localhost:8000 即可，不用重启软件。

提示端口被占用 / 打不开界面？

说明软件已经在运行了（或上次没退干净）。先按上面的方法彻底结束进程，再重新启动。

导出的 PDF 里中文变成空白？

说明系统缺少中文字体（极少见）。Windows 请确认系统字体目录中存在微软雅黑或宋体；也可在「系统设置」页查看环境自检结果。

怎么开通 AI 功能？

向卖家订阅后，你会收到一串授权码，形如 ZN-20261231-A1B2C3D4。
打开「系统设置 → AI 功能授权」，把授权码粘贴进去，点「激活」，完成。
你不需要注册任何 AI 账号，也不需要填写 API Key，整个开通过程就是粘贴这一串码。

AI 功能提示「未授权」或「已过期」？

说明授权码没激活或订阅已到期。续费后卖家会发给你一串新的授权码， 在同一个地方重新粘贴激活即可。
授权到期不影响任何其他功能——手动记账、账目明细、税务提醒、报表导出、 加密、多用户权限等全部为买断后终身免费，只有 AI 记账和 AI 查账会暂停。

Mac 上提示「Apple 无法验证…是否包含恶意软件」？

这是 macOS 对未经苹果公证软件的统一拦截，不代表软件有问题。 请参考本文档「二、第一次启动 → Mac」中的方法 A（终端命令），一行命令即可永久解除，只需操作一次。

可以多台电脑同时用吗？

同一局域网内，其他设备可以通过软件启动时显示的「局域网访问」地址访问同一份数据。 若要在不同地点的电脑上使用，需手动复制上面提到的数据库文件。
