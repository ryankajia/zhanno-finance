# Cloudflare 部署 —— 手把手步骤

> 全部在**你自己 Mac 的「终端」**里操作。一次性，约 10 分钟，之后不用再碰。
> 打开终端：按 `Command + 空格`，输入 `终端` 或 `Terminal`，回车。

---

## 第 0 步：进入 worker 目录

复制下面这行，粘贴到终端，回车：

```bash
cd "/Users/huijiajia/Documents/general/公司/项目开发/湛诺财务系统/worker"
```

确认位置对不对：

```bash
pwd
```
应该显示 `.../湛诺财务系统/worker`。

## 第 1 步：登录 Cloudflare

```bash
npx wrangler login
```

- 第一次会问 `Ok to proceed? (y)` → 输入 `y` 回车
- 浏览器会自动打开 Cloudflare 授权页
- 用 **ryankajia@gmail.com** 登录，点 **Allow / 允许**
- 终端出现 `Successfully logged in` 即可

## 第 2 步：部署

```bash
npx wrangler deploy
```

成功后终端会打印出你的服务地址，形如：

```
https://zhanno-ai.xxxxx.workers.dev
```

**⚠️ 把这一行完整复制下来发给我**，我要用它更新安装包。

---

## 第 3 步：填入三把钥匙

一次一条，每条都会让你粘贴内容后回车。
为避免手抄出错，先用命令把内容复制到剪贴板，再直接 `Command + V` 粘贴。

### ① 授权码签名密钥

```bash
cat ../.license_secret | pbcopy
npx wrangler secret put LICENSE_SECRET
```
提示 `Enter a secret value:` 时按 `Command + V` 粘贴，回车。

### ② MiniMax API Key

```bash
grep MINIMAX_API_KEY ../.env | cut -d= -f2 | tr -d '\n' | pbcopy
npx wrangler secret put AI_API_KEY
```
同样 `Command + V` 粘贴，回车。

### ③ MiniMax GroupId

```bash
grep MINIMAX_GROUP_ID ../.env | cut -d= -f2 | tr -d '\n' | pbcopy
npx wrangler secret put MINIMAX_GROUP_ID
```
同样粘贴回车。

---

## 第 4 步：验证

把下面的 `你的地址` 换成第 2 步拿到的地址：

```bash
curl https://你的地址/health
```
期望看到：`{"ok":true,"service":"zhanno-ai-proxy"}`

再测一个真授权码（这个码到 2026-10-23 到期）：

```bash
curl -X POST https://你的地址/v1/verify \
  -H 'Content-Type: application/json' \
  -d '{"license":"ZN-20261023-DB590E27"}'
```
期望看到：`{"valid":true,"expires":"2026-10-23",...}`

**看到这两个结果就说明全部成功了。**

# 日常怎么用（部署完以后的事）

## 客户付款了，怎么发码给他

打开终端：

```bash
cd "/Users/huijiajia/Documents/general/公司/项目开发/湛诺财务系统"
python3 generate_license.py --month
```

会打印出类似：

```
  ✓  ZN-20261023-DB590E27    到期：2026-10-23（剩 30 天）
```

**把 `ZN-` 开头这一串发给客户就行。** 客户在软件「系统设置 → AI 功能授权」粘贴、点激活，完成。

其他用法：
```bash
python3 generate_license.py --year         # 一年后到期
python3 generate_license.py 2026-12-31     # 指定日期到期
```

## 客户续费

再生成一个新码发过去，客户重新粘贴即可。**旧码到期自动失效，你什么都不用做。**

## 发现有人把码到处分享

编辑 `wrangler.toml`，把那个码填进 `BLOCKED_CODES`：

```toml
BLOCKED_CODES = "ZN-20261023-DB590E27"
```
然后 `cd worker && npx wrangler deploy` 重新部署，该码立即失效。

**客户端不用重装，客户完全无感。**

# 安全须知

| 东西 | 放在哪 | 客户能看到吗 |
|---|---|---|
| MiniMax API Key | 只在 Cloudflare Secret | ❌ 永远看不到 |
| 授权码签名密钥 | Cloudflare Secret + 本机 `.license_secret` | ❌ 永远看不到 |
| 授权码 `ZN-...` | 发给客户 | ✅ 这就是给他的东西 |

⚠️ **`.license_secret` 请立刻备份到密码管理器或私人网盘。**
丢了就再也生成不出 Worker 认可的授权码，所有客户都得重新发码。

⚠️ **绝对不要把 MiniMax API Key 发给任何客户。** 那是你的付款凭证，不是月票。
